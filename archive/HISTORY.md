# Historical snapshots

Chronological index of major dossier checkpoints. Newest at top. Each entry: date, label, one-sentence description, and links to the snapshot directory and git tag.

Snapshots capture the synthesis files (`dossier.md` plus the three `analysis/*.md` documents) as they stood on the given date. Case-file revision history lives inline within each case file via `*(updated YYYY-MM-DD)*` markers and `## Update — YYYY-MM-DD` blocks.

Forward checkpoints (today and onward) include a snapshot directory under `archive/snapshots/`. Retroactive entries are tags only — recover those states with `git checkout <tag>`.
